1. Architecture & Tech Stack

The system is designed as a self-contained local web application. It requires no installation, database engine setup, or internet access on client machines.

Layer Technology Technical Implementation Details
Frontend React 18.3 & Zustand Unified reactive view engine. Zustand hooks manage instant store updates, keeping changes persistent across re-focus events.
Visuals Recharts & Lucide Dynamic rendering of charts and modern iconography. Fully responsive inline graphics that handle screen shifts smoothly.
Backend Express.js & Multer Lightweight local web server. Handles REST routes, parses payloads, and processes binary multipart form uploads.
Excel ExcelJS (Native JS) Reads and edits spreadsheet workbooks. Performs cell checks based on font colors (RGB, theme, indexed), updates text columns, and strips workbook security properties.
Sandbox Portable Node.js v22 A local binary directory. The startup script adds this binary path to the session, launching the tool on any Windows PC.

The DSM Operations Hub is the collaborative workspace designed to manage task workloads, sprint burndowns, metrics reviews, and Daily Status Report generation.

Page 2.1: Overview Dashboard

How to use: Open the workspace. Observe the top KPI cards summarizing Active Tasks, Review Pending, Blocked Tasks, and Total Delivered. Check the dark-blue gradient "AI Analysis Center" block. It presents a live computed risk percentage, a bandwidth summary, and recommended action cards (like unblocking critical milestones).

How to use: Use this registry page to manage all deliverables. Click **"Add Task"** to open the task details modal. Input details like Task ID (serial/numbers), Function Name, and Task Type (e.g. Validation, Automation). 3. Part II: My Tracker (Isolated Personal Workspace)

My Tracker is the personal time-tracking and productivity environment designed to organize individual focus sessions, breaks, and daily targets offline.

Tab 3.1: Dashboard

How to use: Open My Tracker. On the Dashboard tab, click the green **"Punch In"** button on the header to start your shift. The active hours timer will begin ticking. Observe the circular progress ring showing the percentage of your target shift completed (e.g. 74%). Use the quick action cards below to quickly log work units, add checklist items, or jot down markdown notes.

Tab 3.5: Notes

How to use: Click the Notes tab. This is an integrated Markdown text editor. The left panel shows your folders (like Work, Personal) and documents. Click on a document title to load it, or click **"New Note"** to create a blank document. Type your content on the right. You can write headings using `#`, list items using `-`, and use simple bold or italic text styles. Your notes are saved automatically in the local database.

4. Demo Execution Script

To deliver a flawless demo, perform the following actions:

  • 00:00 - Launch: Click `start.bat` and explain that it runs locally off portable Node.js binaries.
  • 01:00 - Hub Overview: Show the four stat cards and AI command suggestions in the **DSM Operations Hub**.
  • 02:00 - Edit Data: Navigate to "DSR Generator", click "Edit Data", change Completed FTs and Today FTs, and click "Store Saved Data".
  • 03:00 - MOM Export: Click "Copy DSM-MOM to Outlook" and explain how the formatted grid copies directly to Outlook.
  • 04:00 - Time logs: Return to Portal and launch "My Tracker" to demonstrate punching in shifts and logging personal hours.
